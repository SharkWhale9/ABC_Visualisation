Method 01 · independent prior proposals

ABC rejection sampling

Draw parameters from the prior, simulate one epidemic, and keep the proposal when its normalized summary distance is below ε. The method is transparent and parallelizable, but a strict tolerance can discard most of the simulation budget.

Method 02 · dependent local proposals

ABC-MCMC

Start in the ABC-compatible region, propose nearby parameters with a Gaussian random walk, and accept only in-bounds proposals whose fresh simulation falls below ε. Rejection repeats the current state, creating the flat stretches visible in the traces.

β and γ trace plots

The first 500 states are burn-in. Long flat stretches signal repeated rejections; gradual movement and repeated visits indicate local exploration.

Dependent states

The next proposal is centered on the current state, so retained draws are autocorrelated and must not be interpreted as independent simulations.

Acceptance rule

With uniform priors and a symmetric random walk, an in-bounds proposal is accepted exactly when its simulated distance is below ε. Out-of-bounds proposals cost no SIR simulation.

Tuning and burn-in

Small σ values create sticky local moves; large values produce more invalid or poor-fit proposals. Burn-in removes dependence on the initialized state.

Model check

Does the stochastic simulator behave sensibly?

For each parameter regime, 500 seeded stochastic trajectories are compared with the deterministic SIR ODE. The ensemble mean should follow the reference while individual outbreaks retain realistic process noise.

Numerical checks

Validation diagnostics

Every state in all 1,500 trajectories is checked for population conservation, non-negativity, and valid compartment movement; trajectory error is then summarized against the ODE reference.

Supercritical outbreaks

Expected small differences

The daily binomial process is not algebraically identical to the continuous-time ODE, so discretization and nonlinear averaging produce modest offsets.
